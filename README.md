# Molekula — платформа обучения

Сайт: https://molekula-teach-ai.github.io/

## Как добавить урок

Список уроков хранится в файле [`lessons.json`](lessons.json) — сайт берёт уроки прямо отсюда.

1. Откройте [`lessons.json`](lessons.json) и нажмите значок карандаша (**Edit this file**).
2. Добавьте новый блок **в конец** списка `lessons`. Между блоками нужна запятая, после последнего — нет:

   ```json
   {
     "course": "Жүйелі ойлау",
     "lessons": [
       {"title": "Первый урок", "video": "k7TpolKgRSM"},
       {"title": "Второй урок", "video": "BRaSlOkSQL4"},
       {"title": "Новый урок", "video": "https://youtu.be/xxxxxxxxxxx", "duration": 25}
     ]
   }
   ```

3. Нажмите **Commit changes**. Через 5–6 минут урок появится на сайте.

| Поле | Обязательно | Что писать |
|---|---|---|
| `title` | да | Название урока |
| `video` | да | Ссылка на видео YouTube или его ID (11 символов) |
| `duration` | нет | Длительность в минутах, числом без кавычек, например `25` |
| `course` (в самом верху) | нет | Название курса |

### Важно

- **Номер урока = его позиция в списке.** Добавляйте новые уроки только в конец, не меняйте порядок и не удаляйте старые: прогресс учеников привязан к номеру.
- У видео должны быть субтитры (казахские, русские или английские) и доступ по ссылке — по ним работает ИИ-помощник и генерируются тесты.
- Ученики, уже прошедшие все прежние уроки, получат новый урок открытым автоматически.
- После коммита откройте вкладку **Actions**: зелёная галочка — файл корректен, красный крестик — в тексте ошибки написано, что исправить. Пока файл с ошибкой, сайт продолжает показывать последнюю корректную версию.

## Сабақ құралдары (`tools`)

Сабаққа интерактивті құралдар қосуға болады — олар бейненің астында «Сабақ құралдары» блогында шығады.
Құралдан «← Сабаққа оралу» батырмасы оқушыны сол сабаққа қайтарады.

```json
{"title": "Ерітінді ортасын индикатормен анықтау", "video": "https://youtu.be/xxxxxxxxxxx", "duration": 3,
 "tools": [
   {"type": "lab", "title": "Цифрлы зертхана", "url": "digital-lab/", "note": "Үлгі → индикатор → болжам → журнал"}
 ]}
```

| Өріс | Не жазу керек |
|---|---|
| `title` | Құралдың атауы |
| `url` | Сайт ішіндегі бет (`digital-lab/`, `vrar-molecules/#nacl`) немесе толық сілтеме `https://…` (жаңа бетте ашылады) |
| `type` | Белгіше: `lab`, `ar`, `3d`, `file`, `link` (міндетті емес) |
| `note` | Қысқа түсініктеме (міндетті емес) |

Қазір бар құралдар: `digital-lab/` — цифрлы зертхана, `vrar-molecules/` — AR молекулалар (`#water`, `#co2`, `#ch4`, `#nacl`), `files/nacl_project.blend` — NaCl торының Blender жобасы.
